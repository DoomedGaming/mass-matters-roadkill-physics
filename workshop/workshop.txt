description=[h1]Mass Matters: Roadkill Physics - Release 1.0.0[/h1]
description=[b]Compatibility: tested only on Project Zomboid Build 42.20 stable.[/b]
description=
description=[h1]Why this mod exists[/h1]
description=Build 42.20 can give tiny animals and bodies a wildly disproportionate effect on vehicles. A live mouse, rat, or rabbit can heavily slow a normal car, while driving over a corpse can pitch or launch even a heavy vehicle. Mass Matters makes those reactions respect the thing being hit instead of treating vehicle mass as the deciding force.
description=
description=[h1]What it changes[/h1]
description=[list]
description=[*][b]Live animals:[/b] replaces the oversized vehicle reaction with a mass-aware response. This applies to regular cars as well as heavy vehicles.
description=[*][b]Zombie and animal corpses:[/b] replaces disproportionate wheel lift and torque with a mass-aware response.
description=[*][b]Live zombies:[/b] adds a separate setting for the initial horizontal slowdown when a vehicle hits a standing zombie. Keep vanilla slowdown, reduce it, or remove that horizontal impulse.
description=[/list]
description=
description=[h1]Sandbox options[/h1]
description=[list]
description=[*][b]Live animal vehicle reaction[/b] - 0.0 to 2.0; default 1.0 is the intended mass-aware result.
description=[*][b]Corpse vehicle reaction[/b] - 0.0 to 2.0; default 1.0 is the intended mass-aware result.
description=[*][b]Live zombie forward slowdown[/b] - 1.0 keeps vanilla slowdown, 0.5 keeps half, and 0.0 removes the targeted horizontal impulse.
description=[/list]
description=Animal and corpse reactions are capped so the mod cannot make them stronger than Build 42.20 vanilla. Multiplayer administrators can apply tuning changes while the server is running; connected clients receive them without reconnecting.
description=
description=[h1]Important live-zombie limitation[/h1]
description=The zombie setting controls the initial horizontal pedestrian impulse. Once a living zombie is prone beneath the wheels, Build 42.20 uses separate private per-wheel lift and torque state that a release-safe Lua mod cannot read or scale. That prone living-zombie reaction remains vanilla and can still affect handling in a crowd. Corpse wheel reactions use a different accessible path and are adjusted by this mod.
description=
description=[h1]Pure mod and multiplayer support[/h1]
description=This is an ordinary Lua-only Workshop mod. It does not patch projectzomboid.jar, install Java classes, replace the launcher, or modify game files. It supports single-player, listen servers, and dedicated multiplayer servers through Project Zomboid's normal Workshop mod flow. Existing saves do not need migration; a server still needs its normal restart when first enabling a new mod.
description=
description=[h1]Deliberately unchanged[/h1]
description=Target damage and death, vehicle-part and wheel damage, hit sounds, traction, drivetrain behavior, wall and tree impacts, and vehicle-to-vehicle collisions remain vanilla.
